# Oriental Sports — Pune

> **GEAR. COURTS. PUNE.**  
> Pune’s sports house. Gear for the game. Courts for the city.

A production-grade, responsive, mobile-first ecommerce and sports infrastructure web application for **Oriental Sports** (Shop 247, MG Road, New Modikhana, Camp, Pune 411001).

---

## ⚡ Highlights

- **Official Brand Mark**: Concentric black rings, brushed gold italic `S`, bold geometric `ORIENTAL`, italic gold `SPORTS`, and gold underline bar.
- **Two Core Pillars**:
  - **SHOP**: Equipment across Cricket, Tennis, Pickleball, Badminton, Table Tennis, Squash, Fitness, and Recreation.
  - **BUILD**: Turnkey sports infrastructure for Pickleball, Tennis, Badminton, Squash, and Synthetic Turf sports arenas.
- **21st.dev Interaction Patterns**:
  - Scroll-driven media expansion hero with kinetic staggered text reveals.
  - Magnetic CTA buttons with spring cursor attraction on desktop.
  - Sticky scroll-driven court engineering storytelling (5 stages).
  - Signature Shop by Sport interactive desktop list with real-time visual crossfade and mobile swipe reel.
  - Spotlight cards with dynamic mouse light sheens.
  - State-morphing animated header with sliding gold indicators.
- **Full Ecommerce Capability**:
  - Centralized catalog data architecture (`src/data/products.ts`, `src/data/categories.ts`, `src/data/courts.ts`, `src/data/media.ts`).
  - Mobile slide-over bag drawer with free Pune delivery tracker.
  - Dedicated cart page with Pune delivery / Camp store pickup selection.
  - Instant live search modal with keyboard navigation.
  - Simulated checkout with UPI, Card, NetBanking, and direct WhatsApp order generation to `+91 98909 90022`.
- **Camp Store Integration**:
  - Detailed store locator, live Google Maps directions, phone calling, and in-store stringing services.

---

## 🛠 Tech Stack

- **Framework**: React 18 + Vite + TypeScript
- **Routing**: React Router v6
- **Animations & Motion**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Google Fonts (Bebas Neue, Barlow Condensed, Space Grotesk, Outfit)
- **Styling**: Pure Modern CSS with Design Tokens (`tokens.css`, `global.css`, `navigation.css`)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm (v9+)

### Installation

```bash
# Clone the repository
git clone https://github.com/pratikjadhav8900/oriental_sports.git

# Navigate to project directory
cd oriental_sports

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Building for Production

```bash
npm run build
```
